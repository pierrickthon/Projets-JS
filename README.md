# Projet JS 

Ce sont diiférents projets personnels codés en Javascript pour m'améliorer dans ce langage de programmation. Ces projets sont entre autres : un générateur de mot de passe, le jeu tic_tae_toe, un site animé et un site de To-Do List que j'utilise régulièrement pour m'organiser dans mes tâches du quotidien.
